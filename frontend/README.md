## Estrutura do Projeto

O projeto consiste em três aplicações:

- **Mobile (passageiros)** — aplicativo Flutter para os passageiros do cruzeiro
- **Web desktop (tripulação)** — painel React para gestão do operação no navio
- **Web desktop (companhia)** — painel React para gestão operacional da companhia

## Por que Flutter para mobile?

Flutter é um framework otimizado para aplicativos móveis, oferecendo alta performance e experiência nativa em iOS e Android com uma única base de código. Como o aplicativo dos passageiros é a vitrine digital do cruzeiro, a escolha prioriza uma experiência fluida e profissional.

## Por que React para o desktop?

O painel da companhia exige dashboards complexos com gráficos, tabelas e dados em tempo real. O React possui um ecossistema mais maduro para esse tipo de interface, com bibliotecas como Recharts para visualização de dados e melhor performance no navegador.
